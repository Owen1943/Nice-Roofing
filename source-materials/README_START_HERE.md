# NICE ROOFING & FLOORING — ChatGPT Work Starter Pack

## How to use
1. Upload **this ZIP** to a ChatGPT Work conversation (or extract it and upload the extracted folder/files).
2. Instruct Work to **open `MASTER_WEBSITE_PROMPT.md` and execute the complete brief**, using the included images and lens source.
3. Ask Work to build, test and package the actual website, not just generate a plan.
4. Supply deployment/domain/email credentials only using secure project environment tools as needed, never paste production secrets into frontend code.

## Folder guide
- `MASTER_WEBSITE_PROMPT.md`: the complete detailed website build prompt.
- `references/lens_component_original.txt`: the original user-supplied shadcn/React lens and demo code, to be adapted.
- `assets/ai_enhanced/`: 10 AI-generated visual interpretations/enhancements from screenshots (not documentary proof).
- `assets/source_screenshots/`: 10 original user-provided screenshots for checking project authenticity and brand language.

## Critical content integrity warning
The enhanced graphics are AI-generated interpretations and sometimes DIFFER from photographed roofs, buildings, text and material finishes. They must not be represented as completed business projects without owner permission and source verification. Original screenshots are limited-resolution references; ask the owner for the genuine full-resolution photos, logo artwork and authoritative product facts.

The Instagram reference was assessed using its public caption, not its inaccessible video playback.
